# Documentación de LifeSync (para Claude Code)

Esta carpeta contiene la documentación clave del proyecto convertida a Markdown limpio para que Claude Code pueda leerla fácilmente con el Filesystem MCP.

## Archivos

| Archivo                        | Contenido                                      |
|--------------------------------|------------------------------------------------|
| `00-proposito.md`              | Propósito del Sistema (PdS)                    |
| `01-requerimientos.md`         | RF-01 a RF-19 + resumen de RNF                 |
| `02-sprint-planning.md`        | Épicas + detalle completo del Sprint 1         |
| `03-arquitectura-y-stack.md`   | Stack, Clean Architecture y decisiones clave   |
| `CLAUDE.md`                    | Instrucciones específicas para Claude Code     |

## Cómo usar con Claude Code

Simplemente decile:

```
Leé los archivos de la carpeta docs/ y especialmente CLAUDE.md. 
Luego ayudame a empezar con el Sprint 1.
```
